# 软考中项知识库（系统集成项目管理工程师）

离线可用的单文件学习刷题站，面向零基础备考新人，目标：**学完即可通过软考中级「系统集成项目管理工程师」**（第3版教材 / 机考新大纲）。

## 使用

无需安装任何东西：双击打开 `ruankao/index.html`（或站点根目录的 `index.html`）即可，进度自动保存在浏览器 localStorage。

| 功能 | 说明 |
|---|---|
| 仪表盘 | 总进度环、三板块进度、学习路线推荐 |
| 章节学习 | 知识点卡片：定义 + 对比表格 + 结构图示 + 考题坑点 + 助记口诀；可标记掌握/收藏 |
| 刷题实战 | 按章刷选择题，即时判分 + 解析 + 考点标注 |
| 错题本 | 自动收集错题，重刷直至消灭 |
| 搜索 | 全库知识点关键词检索 |
| [知识图谱](graph.html) | 交互式联想学习：258 个知识点连成网络，前置/后继/关联一目了然，点击直达对应章节卡片 |

## 内容规模与章节地图

18 章 / 229 张知识点卡片 / 218 道题，按三大板块组织：

| 板块 | 章节 | 定位 |
|---|---|---|
| 项目管理核心 | 9–14 章（概论/启动/规划/执行/监控/收尾） | 案例主战场，两科通吃，最高优先级 |
| IT 技术基础 | 1–8 章（信息化/信息技术/IT服务/架构/软件工程/数据工程/系统集成/信息安全） | 基础知识科分值大户 |
| 辅助知识 | 15–18 章（组织保障/监理/法律法规/职业道德） | 考前突击，高性价比 |

选题与高频定级依据近 5 年真题考频分析（见 `data/exam-analysis.md`）；重点覆盖案例必考的挣值计算（含完整例题）、变更控制、配置管理、风险全过程等。

## 知识图谱（graph.html）使用说明

导航栏「🧠 知识图谱」进入全屏交互图谱：**258 个知识点节点 / 413 条关系边**，初始只显示三大板块 + 18 章节 + 3 个考试专题（约 24 个节点），单击渐进展开，把孤立的章节知识点连成网络。

| 操作 | 说明 |
|---|---|
| 展开子知识点 | 单击板块/章节节点展开下一级，再点收起（章节同时最多开 3 个，防过乱） |
| 聚焦模式 | 单击任意知识点：**红虚线箭头=前置**（先学）、**蓝实线箭头=后继**（后学）、**灰点线=关联**（搭配出题），无关节点淡化；点空白恢复 |
| 跳转学习 | 面板中前置/后继/关联词可点击跳选；「📖 查看完整内容」直达对应章节卡片（深链 `index.html#c章-卡`） |
| 搜索 | 顶栏搜索框按名称/标签模糊匹配，选中后自动展开父级链路并居中定位 |
| 快捷视图 | 「全部展开 / 一键收起 / 只看核心考点（5星金描边）」 |

三端适配：
- **手机（<768px）**：详情面板为底部抽屉（默认 56vh，上滑全屏、下滑关闭）；工具栏紧凑两行，搜索框独占一行；节点点击热区 ≥44px
- **平板（768~1024px）**：右侧可收起抽屉（约 330px），横竖屏切换自动重排且不丢选中状态
- **桌面（≥1024px）**：左侧图谱 + 右侧 340px 详情双栏；hover 节点显示章节/重要度提示

图谱数据维护：编辑 `scripts/build-graph.js`（精修表 PATCH、前置边 PR、关联边 REL），运行 `node scripts/build-graph.js` 重新生成 `data/graph-data.json`（规范数据）与 `data/graph-data.js`（file:// 兜底加载用）。节点/URL 由 `data/ch01~ch18.js` 自动派生，章节卡片增删后重跑即可同步。

**实现要点**：① 数据为「节点+边」分离结构，`contains/prerequisite/related` 三种边严格区分线型，prerequisite 方向恒为"前置→后学"；② 渐进展开靠 `expanded` 集合增量 setOption，配合内部布局坐标捕获实现平滑过渡；③ 聚焦模式按可见对计算三度关联集合，逐节点/边调透明度；④ ECharts 优先加载仓库内本地副本（`../gkzn/_shared/js/echarts.min.js`，5.6.0），失败回退 jsDelivr CDN，保证 file:// 双击与离线可用；页面卸载时 dispose。

## 项目结构与维护

本项目为「源文件分离开发、单文件合并发布」架构：

```
ruankao/
├── index.html          发布物（唯一，含全部数据）—— 禁止手改数据区
├── graph.html          知识图谱页（独立页面，ECharts 力导向图）
├── data/ch01~ch18.js   数据源：每章一文件（格式契约见 data/SPEC.md）
├── data/graph-data.json/js  知识图谱数据（由 scripts/build-graph.js 生成，勿手改）
├── data/SPEC.md        写作规范与 checklist
├── data/exam-analysis.md  近5年真题考频分析
└── scripts/
    ├── merge.js        构建器：build / check / sync
    └── build-graph.js  知识图谱数据构建器
```

**修改任何内容的标准流程**（详细规范见 [AGENTS.md](AGENTS.md)）：

```bash
cd ruankao
# 1. 编辑 data/chNN.js（N=目标章号）
node scripts/merge.js   # 2. 构建+校验+同步根副本，一步完成
# 3. 浏览器打开 ruankao/index.html 冒烟验证
```

构建为幂等重建：18 个源文件整体重新生成 index.html 数据区，并校验语法、字段完整性、源与产物一致性；`/workspace/index.html` 站点根副本由 sync 自动同步。
