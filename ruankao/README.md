# 软考中项知识库（系统集成项目管理工程师）

离线可用的单文件学习刷题站，面向零基础备考新人，目标：**学完即可通过软考中级「系统集成项目管理工程师」**（第3版教材 / 机考新大纲）。

## 使用

无需安装任何东西：双击打开 `ruankao/index.html`（或站点根目录的 `index.html`）即可，进度自动保存在浏览器 localStorage。

| 功能 | 说明 |
|---|---|
| 仪表盘 | 总进度环、三板块进度、学习路线推荐 |
| 章节学习 | 知识点卡片：定义 + 对比表格 + 结构图示 + 考题坑点 + 助记口诀；可标记掌握/收藏 |
| 刷题实战 | 按章刷选择题，即时判分 + 解析 + 考点标注 |
| 错题本 | 自动收集错题，重刷直至消灭 |
| 搜索 | 全库知识点关键词检索 |

## 内容规模与章节地图

18 章 / 229 张知识点卡片 / 218 道题，按三大板块组织：

| 板块 | 章节 | 定位 |
|---|---|---|
| 项目管理核心 | 9–14 章（概论/启动/规划/执行/监控/收尾） | 案例主战场，两科通吃，最高优先级 |
| IT 技术基础 | 1–8 章（信息化/信息技术/IT服务/架构/软件工程/数据工程/系统集成/信息安全） | 基础知识科分值大户 |
| 辅助知识 | 15–18 章（组织保障/监理/法律法规/职业道德） | 考前突击，高性价比 |

选题与高频定级依据近 5 年真题考频分析（见 `data/exam-analysis.md`）；重点覆盖案例必考的挣值计算（含完整例题）、变更控制、配置管理、风险全过程等。

## 项目结构与维护

本项目为「源文件分离开发、单文件合并发布」架构：

```
ruankao/
├── index.html          发布物（唯一，含全部数据）—— 禁止手改数据区
├── data/ch01~ch18.js   数据源：每章一文件（格式契约见 data/SPEC.md）
├── data/SPEC.md        写作规范与 checklist
├── data/exam-analysis.md  近5年真题考频分析
└── scripts/merge.js    构建器：build / check / sync
```

**修改任何内容的标准流程**（详细规范见 [AGENTS.md](AGENTS.md)）：

```bash
cd ruankao
# 1. 编辑 data/chNN.js（N=目标章号）
node scripts/merge.js   # 2. 构建+校验+同步根副本，一步完成
# 3. 浏览器打开 ruankao/index.html 冒烟验证
```

构建为幂等重建：18 个源文件整体重新生成 index.html 数据区，并校验语法、字段完整性、源与产物一致性；`/workspace/index.html` 站点根副本由 sync 自动同步。
