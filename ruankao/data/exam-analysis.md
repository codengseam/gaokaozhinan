# 软考中级《系统集成项目管理工程师》近5年（2021-2025）真题考点-章节映射报告

> **用途**：供知识点写作 Agent 使用，作为章节详略取舍与考点覆盖的依据。
> **章节体系**：《系统集成项目管理工程师教程（第3版）》（清华大学出版社，2024年1月出版），共18章。
> **数据来源**：多轮网络检索（真题回忆版、培训机构考情分析、考生博客解析等）交叉验证。机考后官方不再公布真题，2023下半年起的考情基于考生回忆版，颗粒度有限；分值为约数，仅供参考。
> **说明**：标注"（待验证）"处为单一来源或不确定信息；本报告不引用具体题号，考频判断以"多批次/多年度反复出现"为准。

## 五、给写作Agent的优先级建议

### 第一梯队（必须详写，含公式/流程/口诀/例题，篇幅占比≥60%）
1. **第11章 规划过程组**：全章详写。重点：WBS、关键路径与网络图、三点估算、应急/管理储备、质量成本、风险规划工具（SWOT/概率影响矩阵）、采购三文件（SOW/采购管理计划/采购策略）。案例+选择题双料第一大户。

3. **第15章 组织保障**：详写配置管理（配置库/配置项状态/六活动/审计）与变更管理（七步法/CCB）——案例超高频但篇幅小，投入产出比最高。
4. **第10章 启动过程组 + 第9章 项目管理概论**：详写项目章程12项内容与审批要点、干系人五种分类方法、立项管理与可行性研究（内容+方法）。
5. **第12章 执行过程组**：详写塔克曼五阶段、冲突管理、管理项目知识（新大纲新贵）、沟通方法三类、实施采购程序。
6. **第14章 收尾过程组**：中等篇幅但要点全（最终报告、经验教训、行政收尾），因章节小、易得分。

### 第二梯队（正常篇幅，覆盖高频选择考点）
7. **第2章 信息技术发展**：技术板块分值最高。重点：OSI七层、存储三模式、云IaaS/PaaS/SaaS、物联网三层、大数据特征、5G三场景、加密体系。
8. **第8章 信息安全工程**：CIA、对称/非对称+国密、数字证书、等保2.0流程与分级、攻击类型。

### 通用写作要求
- 每个高频考点应包含：**定义 → 关键数字/公式 → 真题型判别技巧（选择题坑点）→ 案例问法与答题模板**。
