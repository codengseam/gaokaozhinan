## 二、chNN.js 文件格式契约（严格遵守）

每个文件内容 = **一个完整 JS 对象字面量**（不带数组括号），形如：

```js
{id:2,  title:'信息技术发展',  sec:'it',  page:50, cards:[
  {t:'卡片标题', f:'high', s:3, m:'一句话助记口诀', b:`
<p><b>正文 HTML……</b></p>`},
  // ……更多卡片
], quiz:[
  {q:'题干（ ）', o:['选项A','选项B','选项C','选项D'], a:1, k:'考点名', e:'解析：为什么选它、其他选项为什么错。'},
  // ……更多题目
]},
```

### 字段规则
| 字段 | 类型 | 规则 |
|---|---|---|
| id / title / sec / page | — | **从占位行原样照抄**，一字不改 |
| cards.t | string | 单引号；标题≤16字；不重复 |
| cards.f | 'high'\|'mid'\|'low' | 真题高频=high，常考=mid，了解=low（参考 exam-analysis.md） |
| cards.s | 1-3 | 星级：3=必背，2=常考，1=了解；与 f 正相关 |
| cards.m | string | 助记口诀，≤30字，尽量押韵/对仗 |
| cards.b | template literal | **反引号包裹的 HTML**；内部禁止出现反引号和 `${`；换行随意 |
| quiz.q | string | 单引号；题干末尾空缺用（ ） |
| quiz.o | string[4] | 恰好4个选项，长度相近；干扰项要有迷惑性 |
| quiz.a | 0-3 | 正确答案下标；同一章内答案分布要打散（不能全A） |
| quiz.k | string | 考点名，≤12字 |
| quiz.e | string | 解析 ≥40字：先说正确项依据，再点破主要干扰项 |

### 硬性禁令
1. 卡片 b 内禁止 `<script>`、`<style>`、`on*` 事件属性、外链 `<img>`、`<a href>`
2. 所有字符串用单引号；字符串内部若需引号用「」或转义 `\'`，禁止双引号包裹字符串
3. quiz 选项 `o` 内禁止出现单引号（用"的/之"改写），避免转义错误
4. 禁止编造不存在的标准编号/数字（如 GB/T、等保级别、ITSS 编号）；拿不准就不写编号只写名称
5. 每个 chNN.js 写完必须自跑：`node -e "const fs=require('fs');const c=fs.readFileSync('data/chNN.js','utf8');new Function('return ['+c.replace(/,$/,'')+']')();console.log('OK')"`（在 /workspace/ruankao 目录下）

## 三、卡片正文 HTML 白名单

可用标签：`<p> <ul> <li> <b> <table class="kt"><tr><th><td> <figure class="kd-fig"> <figcaption> <div class="dg|dg-row|dg-2|dg-3|dg-box|dg-harrow|dg-varrow|dg-pill|dg-note"> <span> <svg class="tri">`

可用 class（**仅限这些**）：
- `table.kt` —— 对比表格（属性/特征/阶段类知识首选）
- `div.pit` —— 考题坑点（高频陷阱，必配 `<b>坑点：</b>` 前缀风格）
- `div.tip` —— 技巧/提示
- `figure.kd-fig` + `div.dg` 系列卡片图（结构/层级/流程图示）
- dg-box 内部结构固定：`<div class="dg-box"><b>名称</b><span>说明</span></div>`

标签必须闭合、层级正确；表格每行 `<td>` 数量一致；纯文本段落别裸放，用 `<p>` 包。

## 四、内容风格（对齐已完成的第1/9/10/11章）

1. **说人话**：先一句话本质定义，再展开；新人零基础能懂
2. **应试导向**：每个卡片围绕"考试考什么、怎么坑你"组织；多用 pit 标注干扰项套路
3. **口诀**：数字类知识必须给口诀（如"6要素：资网用产人规"）
4. **表格化**：≥2个并列要点的知识优先用 table.kt
5. **图示**：每章至少 1 个 dg 系列结构图（重要章节 2-3 个）
6. **引用网上资料**：写作时可 WebSearch 佐证（第3版教材表述、2024/2025 真题回忆、官方标准），表述以教材术语为准；不确定的说法不写
7. 篇幅：单卡片正文 150-400 字之间；口诀+坑点是灵魂
